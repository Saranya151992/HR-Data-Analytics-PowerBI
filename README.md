# HR Data Analytics Power BI Dashboard

Interactive HR Analytics Dashboard evaluating active employee count, attrition, average age distribution, work experience, and job satisfaction metrics using Power BI.

## 🛠️ Tools & Technologies
- **Data Visualization & Dashboarding:** Power BI Desktop
- **Data Processing & Analysis:** Power Query, DAX, SQL

## 🔑 Key Metrics Analyzed
- Active Employee Count & Attrition Rates
- Average Age Group & Employee Experience Distribution
- Job Satisfaction Scores across Departments
